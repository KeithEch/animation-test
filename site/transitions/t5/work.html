Page transitions · T5 · Colour bars

Selected work

Open a project, then use the browser's Back button (or swipe back on a phone). Watch both directions.

Effect
On click, four bars (red, orange, yellow, sky blue) rise from below and grow until they cover the screen (720ms). The new page loads underneath, then the bars sweep up and away (about 800ms).
Approach
A small script covers the page, then navigates; the reveal on the new page is a CSS animation that starts by itself. Transform only.
Feel
Bold and branded. Every navigation takes about 1.5 seconds plus loading time, and the next page only starts loading once you click (it's fetched while the bars cover).
Reduced motion
No bars: plain, instant navigation.
Works in
Every browser, including Firefox.
Back button
A plain, instant change (no bars). The page you return to must be fully visible, never left covered.
