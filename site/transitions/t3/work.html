Page transitions · T3 · Scripted fade

Selected work

Open a project, then use the browser's Back button (or swipe back on a phone). Watch both directions.

Effect
On click the page fades out (200ms), then the new page fades in (260ms).
Approach
A tiny script delays navigation while a CSS transition runs; the entrance is a CSS animation. ~0.7 KB JavaScript.
Feel
Similar to T1, but with a brief dip to the background colour between pages, and a 200ms delay before the new page even starts loading.
Reduced motion
No fades: plain, instant navigation.
Works in
Every browser, including Firefox.
Trap handled
Press Back after clicking a link: the page you return to must be fully visible, not faded out.
