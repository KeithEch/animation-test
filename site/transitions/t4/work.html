Selected work

Open a project, then use the browser's Back button (or swipe back on a phone). Watch both directions.

Effect
The new page slides up from the bottom and covers the old one, which sinks back slightly (480ms).
Approach
Cross-document View Transitions with custom keyframes. Transform and opacity only. CSS only, 0 KB JavaScript.
Feel
Bold and app-like. Here for contrast; probably too much for a portfolio.
Reduced motion
Nothing slides: a brief 150ms crossfade.
No support
Firefox (release) and older browsers: a normal instant page change.
