Selected work

Open a project, then use the browser's Back button (or swipe back on a phone). Watch both directions.

Effect
The old page dissolves into the new one (280ms). Nothing moves.
Approach
Cross-document View Transitions: @view-transition { navigation: auto } on both pages. CSS only, 0 KB JavaScript.
Feel
Calm and quiet. Closest to "no transition" while still smoothing the cut.
Reduced motion
The same crossfade, shortened to 150ms (opacity only, no movement).
No support
Firefox (release) and older browsers: a normal instant page change.
