Scroll animation, compared

Small, independent demos of three effects — parallax, fade-in, and page transitions — each built a couple of different ways so they can be judged side by side, on a laptop and on a phone.

Every demo follows the same rules: only transform and opacity move, every page is complete and readable with no JavaScript at all, and every effect has a reduced-motion version. Details and measured numbers are in the repository README.

Performance meter

Turn this on, then open any demo. A small panel shows frame rate live and can run the three-pass thermal test. The setting is remembered on this device.

You can also add ?hud to any demo's address.

Demos

Control

  • Baseline — no effects The same content the demos use, with no motion. Measure this first: it's what the phone does with zero animation, so every other number is read against it.

1 · Fade-in on enter

  • A · CSS scroll-driven Zero JavaScript. The fade follows your finger: scroll slowly and it fades slowly, scroll back and it reverses.
  • B · IntersectionObserver A tiny script triggers a timed fade. It plays once, on its own clock, and finishes even if you stop scrolling.

2 · Subtle parallax

Each opens at the quietest setting (Whisper). Every page has an intensity picker and a grid linking all four approaches at each intensity.

  • A · CSS scroll-driven Zero JavaScript. Runs on the browser's own scroll machinery.
  • B · Hand-written rAF ~60 lines of JavaScript, 1.6 KB. Main thread, and idle when you're not scrolling.
  • C · Motion 29.6 KB. Hands the work to the same native machinery as A.
  • D · GSAP + ScrollTrigger 46.4 KB. Everything in JavaScript on the main thread, every frame.

3 · Page transitions

Each opens on a "Work" list. Open a project, then press Back (or swipe back). Judge both directions. T1, T2 and T4 need Chrome/Edge 126+ or Safari 18.2+. In Firefox they fall back to a normal page change.

  • T1 · Crossfade The old page dissolves into the new. CSS only. The quietest option.
  • T2 · Shared element The header holds still; the project image grows from its card into the page. CSS only.
  • T3 · Scripted fade Fade out, then fade in. 0.7 KB of JavaScript, and works in every browser including Firefox.
  • T4 · Slide-over The new page slides up over the old one. CSS only. The bold option, for contrast.
  • Trap test Page transition + fade-ins + the Back button. A badge checks automatically that nothing is left invisible.
