Fade-in · approach B

IntersectionObserver

Effect
Each block fades in, with a small rise, as it scrolls into view. No stagger.
Approach
IntersectionObserver adds a class; a CSS transition animates it. About 1 KB of JavaScript gzipped, comments included, with no per-frame work.
Feel
Plays on its own clock. Once triggered it finishes even if you stop scrolling, and it plays only once.
Reduced motion
Everything is simply visible. Nothing fades.
No JavaScript
Everything is simply visible. Only the script can hide anything.

Reduced motion is on, so you're seeing the reduced version: everything visible, nothing moves.
